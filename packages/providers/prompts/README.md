# Промпты

Версионируемые шаблоны промптов для языковой модели (Gemini; см. `src/llm.ts`).

Правила:

- Один файл — один шаблон, версия в имени: `moderate-video.v1.ts`. Меняется смысл — новый файл (`.v2`), старый остаётся, пока используется.
- Шаблоны — модули TypeScript (функция с подстановками): так они попадают в сборку worker'а без отдельной загрузки файлов.
- Ответ модели всегда строгий JSON; схема ответа — Zod в `packages/shared/src/moderation.ts`, проверка и повтор — `llmJson`.
- В шаблоны не подставляются имена и персональные данные детей — только возраст и тема.
