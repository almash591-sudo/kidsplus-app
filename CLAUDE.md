# CLAUDE.md

Проект: образовательная контент-система для детей 2–6 лет (детский киоск + родительское PWA + сервер на Railway).
У каждого ребёнка свой Android-телефон (целевое устройство — Samsung Galaxy S20+, Android 13). iOS не нужен.
Полное ТЗ — в `SPEC.md`. Прогресс — в `PROGRESS.md` (создать на этапе 0 и обновлять после каждого этапа).

## Как работать

- Перед началом работы прочитай `SPEC.md` целиком.
- Работай строго по этапам из раздела 11. Не начинай следующий этап, пока текущий не принят.
- В начале этапа напиши краткий план (файлы, решения, вопросы) и дождись подтверждения.
- Каждый этап — отдельная ветка `stage-N-название`, коммиты небольшие и осмысленные.
- Для новой зависимости кратко объясни, зачем она нужна.
- Пиши тесты вместе с кодом; CI должен быть зелёным.
- Если ТЗ неоднозначно или противоречит реальности (API провайдера ведёт себя иначе) — остановись и спроси.

## Жёсткие правила

- Никогда не коммитить секреты. Ключи только в `.env`; в репозитории — `.env.example`.
- Никогда не скачивать видео с YouTube и других платформ — только встраиваемые плееры.
- Контент попадает к ребёнку только после одобрения родителем.
- В детском интерфейсе нет внешних ссылок, поиска и рекомендаций.
- Имя и персональные данные ребёнка не передаются в языковую модель (Gemini) и другие внешние сервисы.
- Все ответы LLM валидируются по Zod-схеме.

## Команды

Требуется Node 24 и pnpm (через corepack). Переменные — скопировать `.env.example` в `.env`.

```sh
pnpm install                       # установка
docker compose up -d db            # локальный PostgreSQL
pnpm db:migrate                    # применить миграции
pnpm dev                           # api :3000, kid :5173, parent :5174, worker
pnpm test                          # Vitest (интеграционные — при заданном DATABASE_URL)
pnpm lint && pnpm typecheck        # проверки как в CI
pnpm format                        # Prettier
pnpm build                         # сборка всех приложений
pnpm db:generate                   # новая миграция после изменения packages/db/src/schema.ts
docker compose --profile full up   # вся система в контейнерах (kid :8081, parent :8082)
bash scripts/build-libbox.sh       # sing-box libbox.aar для киоска (Go, JDK 21, Android SDK + NDK)
```

Киоск для детских телефонов (Android, Capacitor + Java) — `apps/kiosk`, инструкция `docs/kiosk.md`.

Деплой: push → Railway после зелёного CI; инфраструктура — `.railway/railway.ts`, применяется `railway config apply` (см. `docs/railway.md`). Бэкап отложен до тарифа Hobby (см. `docs/backup.md`).
