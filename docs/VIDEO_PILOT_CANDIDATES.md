# KidsPlus — пилотная подборка видео

Составлено 2026-11-11 для ручной проверки перед добавлением в библиотеку и назначением детям.

## Статус проверки

YouTube Data API нашёл кандидатов, которых нет среди уже сохранённых источников и очереди
модерации. У всех ниже API показывает публичность, разрешённое встраивание, доступность в РФ,
длительность 1–10 минут и `madeForKids=true`. Это **первичный фильтр метаданных**, не просмотр
видео и не подтверждение безопасности/качества. У API признак `madeForKids` задаёт автор канала.
Для каждого кандидата нужно открыть официальный YouTube-плеер, посмотреть содержание, выбрать
конкретный фрагмент (1–5 минут), сформулировать три проверочных вопроса и одобрить родителем.

Видеофайлы не загружались и в KidsPlus ничего не добавлялось. Возраст 2 или 5 лет — предварительная
гипотеза по названию; отдельные отметки ниже означают, что тема вероятнее подходит только старшему.
Шесть поисковых запросов к YouTube Data API использовали около 600 единиц квоты; это метаданный
поиск, а не загрузка или просмотр видео. Сразу собирать ещё 250 ссылок не стал: сначала стоит
проверить пилот и понять, какие темы и форматы действительно полезны детям.

## Что показывает production-аудит

- 203 доступных источника YouTube; 23 недоступных: 20 помечены ошибкой плеера `150`, 2 —
  `oembed_unavailable`, 1 — ограничением региона. Ошибка 150 требует отдельного ручного
  перепросмотра: это не тождественно удалённому ролику.
- В очереди модерации 710 записей имеют `Gemini 402` — сервис сообщает об исчерпанных кредитах.
  Это ошибка обработки, а не оценка содержания. Экран модерации запрашивает последние 300 записей,
  поэтому показанное на скриншоте число 253 не является полным числом таких ошибок.
- По источникам, доступным детям, сейчас предметы распределены так: китайский — 68 источников,
  английский — 32, природа — 25, математика и география — по 18, музыка — 15.
- В географии два кандидата имеют почти одинаковое название про энциклопедию материков; перед
  включением достаточно оставить один, если просмотр подтвердит дублирование.

## Ограничения автоматического просмотра

Локального видеопросмотрщика с подключённым агентом в этой сессии нет. `yt-dlp`, `ffmpeg` и
`ollama` на рабочем компьютере не установлены. Поэтому здесь можно искать и отсеивать по метаданным,
но нельзя честно заявить, что просмотрены картинка и звук, выбран подходящий отрезок или составлены
проверенные по нему вопросы. Следующий практический шаг — просмотреть кандидатов в официальном
YouTube-плеере, записать начало/конец фрагмента и только затем составить контрольный тест.

## Следующий этап пилота

1. Смотреть по одной ссылке в официальном плеере, фиксировать пригодный фрагмент и тему.
2. Для выбранного фрагмента написать минимум три вопроса с четырьмя вариантами ответа и одним
   правильным ответом; проверить, что ответ действительно содержится в просмотренном отрезке.
3. Начать с 5–8 проверенных видео (счёт, животные, музыкальные инструменты); географию и английский
   назначать только после проверки содержания для возраста пяти лет.
4. Из-за `Gemini 402` не отправлять видео пачкой в текущую очередь: сначала требуется восстановить
   модерацию либо пройти этот пилот вручную. Ничего не назначать детям без проверки отчёта родителем.
