# План расширения видеотеки KidsPlus примерно до 1000 материалов

## Размер и темы

Production-аудит показал 203 доступных источника YouTube. Для каталога примерно в 1000 источников нужно добавить около 797 новых — после дедупликации и проверки доступности. Это цель общего каталога, а не рекомендация показывать ребёнку тысячу роликов за раз.

Предварительное распределение новых материалов:

| Тема | Новых видео |
|---|---:|
| Естествознание, природа и экология | 200 |
| Математика и логика | 100 |
| Русский язык и грамотность | 100 |
| Английский язык | 80 |
| Китайский язык | 80 |
| Музыка и ритм | 60 |
| География и культуры мира | 90 |
| Россия | 5 |
| Кыргызстан | 5 |
| Здоровье, безопасность и бытовые навыки | 77 |
| **Всего новых** | **797** |

Числа — рабочая квота; после полного аудита существующих материалов её следует скорректировать по предметам и возрастам. У каждого ролика должны быть проверенные возраст, фрагмент от 1 до 5 минут, тема и минимум три вопроса с четырьмя вариантами ответа.

## Текущий статус автоматизации

- Официальный YouTube Data API использован для поиска и проверки метаданных; медиа не скачивалось.
- Эти 10 ID ещё не сверены с production-каталогом на дубли.
- Локальная генерация картинок на рабочем компьютере не предоставляет видео- или аудиоанализ. Здесь нет локальной видеомодели или GPU.
- Production worker уже передаёт публичную ссылку модели напрямую, без скачивания, и создаёт черновик фрагментов и тестов; его текущий провайдер отвечает `Gemini 402`, поэтому очередь стоит на паузе.
- Эти кандидаты не добавлены в production, не назначены детям и не прошли контентную проверку.
