# Промо-ролики

Вертикальные ролики 1080×1920 (сторис, рилсы) собираются из настоящего интерфейса: телефон
ребёнка и кабинет родителя снимаются покадрово на демо-стенде, монтаж — HTML-страница, которую
Chromium снимает кадр за кадром, а ffmpeg кодирует в MP4 вместе с озвучкой: диктор и голос
совёнка из приложения. Музыки в файле нет — её добавляют в соцсети при публикации.

Всё лежит в `scripts/promo/`, кадры и готовые ролики — в `.promo/` (в `.gitignore`).

| Файл            | Что делает                                                                 |
| --------------- | -------------------------------------------------------------------------- |
| `recorder.mjs`  | съёмка: телефон 390×844 ×3, виртуальные часы страницы, кадр — ровно 1/30 с |
| `capture-N.mjs` | сценарий съёмки ролика N: что нажимать, что снимать, что промотать         |
| `stage.js`      | монтажный стол: телефоны, наплывы, титры, облачка с репликами совёнка      |
| `stage.css`     | вид кадра: цвета и шрифты лендинга                                         |
| `video-N.js`    | монтаж ролика N: сцены, титры, движение камеры, расписание озвучки         |
| `voice-N.json`  | текст озвучки ролика N и голоса                                            |
| `voice.mjs`     | озвучка: фразы из voice-N.json → `voice/N/<id>.mp3` (лежат в репозитории)  |
| `render.mjs`    | рендер: превью-кадры или MP4                                               |
| `img/`          | свои объёмные картинки для сцен, которых нет в интерфейсе (лента в №2)     |

## Съёмка

Каждый раз нужен свежий стенд — день ребёнка начинается с пустых колец:

```sh
cd apps/api
DEMO_CLOCK=1 DEMO_NOW=2026-10-25T09:30:00+03:00 DEMO_CLAY=<папка> node --import tsx src/demo/stand.ts
# в другом окне, из корня:
node scripts/promo/capture-1.mjs   # ≈ 4–5 минут, клипы в .promo/clips/1-*
node scripts/promo/capture-3.mjs   # ролик №3 — тоже утром, на своём свежем стенде
```

Ролик №2 снимается вечером, когда уроки уже пройдены:

```sh
DEMO_CLOCK=1 DEMO_FREE=1 DEMO_NOW=2026-10-25T17:30:00+03:00 DEMO_CLAY=<папка> node --import tsx src/demo/stand.ts
node scripts/promo/capture-2.mjs   # клипы в .promo/clips/2-*
node scripts/promo/capture-4.mjs   # ролик №4 — тоже вечером, на своём свежем стенде
PROMO_ONLY=maze,puzzle node scripts/promo/capture-4.mjs   # переснять только эти игры
```

- `DEMO_NOW` — утро дня съёмки (стенд переводит часы).
- `DEMO_CLOCK=1` — съёмка двигает часы стенда вместе с часами страницы (`/__demo/clock`):
  занятия «длятся» по 10 минут, а снимаются за секунды. Без флага эндпоинта нет.
- `DEMO_CLAY` — необязательно: папка с объёмными картинками `<код эмодзи>.webp` (как
  `media/images/clay/` в R2, этап 25). Без неё в уроках будут обычные эмодзи.
- `DEMO_FREE=1` — сегодняшние уроки уже пройдены, у ребёнка открыто свободное время.
- `PROMO_OUT` — куда складывать кадры вместо `.promo/`.

В ролике №4 играет автопилот: игры съёмка добавляет сама, как родитель, а где лежит ответ,
подсказывают data-атрибуты игр (как в e2e). Кроме касания (`tap` — элемент или точка `{ x, y }`)
у камеры есть палец, который ведут: `down`, `move`, `up` и `drag(from, to, sec)` — кружок идёт
за пальцем по кадру за шаг (лабиринт, пазл); `tick(n)` — снять или промотать n кадров.

Модели и worker на стенде нет. С `DEMO_CLOCK=1` «ИИ смотрит» только видео из
`apps/api/src/demo/review.ts` (`DEMO_REVIEWS`, сейчас — `youtu.be/demohedge01`): через 6 секунд
по часам стенда в «Проверке» появляется отчёт. Ответ заготовлен в том же виде, что присылает
модель, и проходит ту же схему.

Клип — папка JPEG-кадров 1170×2532 (кадр снимается с `clip` и `scale: 3`: без них CDP отдаёт
390×844 — так сняты ролики №1 и №2) и `meta.json`: число кадров и что сказал голос телефона
(озвучка на съёмке беззвучная, фразы только записываются). Похвала совёнка случайная, поэтому
монтаж привязывается к порядку и началу фраз («Где…», «Это …»), а не к точному тексту.

YouTube на съёмке не грузится — чужих видео в роликах нет. Превью видео — свои заставки
(`POSTERS` в `recorder.mjs`: объёмная картинка из `DEMO_CLAY` на цветном фоне), а плеер —
заглушка: у родителя с кнопкой «play», у ребёнка «играет» по часам страницы (заставка медленно
наплывает) и на `end` куска заканчивается, как настоящий — дальше звёздочка и вопросы.

На стенде китайский даётся детям труднее остальных предметов: в «Прогрессе» его карточки
попадают в «Повторить» (ролик №3).

## Озвучка

Диктор — «Матильда» (№1, №2) или «Джордж» (№3, №4, мужской голос), совёнок — «Лили», как у детей в
приложении (ElevenLabs `eleven-v4` через ProxyAPI). Фразы — в `voice-N.json`: `id`, голос (`narrator` или `owl`) и текст; `gain` —
поправка громкости голоса в дБ (совёнок громче диктора, поэтому `-3`).

```sh
PROXYAPI_KEY=… node scripts/promo/voice.mjs 1          # недостающие фразы; --force — все заново
```

Ключ ProxyAPI есть только у сервиса worker на Railway. Там скрипт запускают через `node -` с
`PHRASES` (содержимое voice-N.json) и `STDOUT_JSONL=1`, присвоенными в начале скрипта: файлы
приходят строками JSON, их сохраняет `node scripts/promo/voice.mjs 1 --save <вывод>`. 1000
символов стоят ≈ 5 ₽.

Монтаж не знает длину фраз заранее: `render.mjs` меряет каждую ffmpeg-ом (без тишины в конце) и
отдаёт странице, а `video-N.js` ставит фразы по очереди и сцены — под них. Поэтому после
переозвучки или правки текста монтаж сам сдвигается. Если фразы не влезают в ролик, рендер
падает с ошибкой «озвучка не влезает». Фразы совёнка показываются ещё и облачком.

## Монтаж и рендер

```sh
FFMPEG=<путь к ffmpeg> node scripts/promo/render.mjs 1 --at 1,8.5,20   # превью-кадры в .promo/preview/
FFMPEG=<путь к ffmpeg> node scripts/promo/render.mjs 1   # .promo/video-1.mp4, ≈ 2 минуты
```

Нужен ffmpeg с libx264 (`FFMPEG`, по умолчанию — `ffmpeg` из PATH); он же меряет озвучку, так
что нужен и для превью. Рядом с превью-кадрами — `voice-N.json`: когда звучит каждая фраза.
Страница монтажа берёт файлы прямо с диска: `scripts/promo/`, шрифты и картинки лендинга
(`/landing/`), значки игр детского приложения (`/games/`) и клипы.

На выходе H.264 High, 30 к/с, CRF 17, AAC 48 кГц. Звук сведён к громкости соцсетей: −14…−15 LUFS,
пик не выше −1,5 dB. `faststart` — подходит для Instagram, VK и Telegram. Ролик без
`voice-N.json` получает дорожку тишины.

Титры не заходят в верхние ~14 % и нижние ~20 % кадра: там интерфейс соцсети.

## Ролики

1. **«Мультик на 5 минут»** — экран сам знает меру: уроки → награда → свободное время по
   таймеру → «На сегодня всё» → мама видит всё в «Пульте» и добавляет 10 минут. Призыв —
   написать «Хочу подключить» в директ. Озвучка — 16 фраз диктора и 5 фраз совёнка.
2. **«Алгоритм подсовывает странное»** — безопасность. Тёмная лента «обычного» видеоприложения:
   мультики, потом кликбейт («НЕ СМОТРИ НОЧЬЮ!»). Лента нарисована на странице из своих
   объёмных картинок (`img/`), чужих кадров нет. Дальше: у Зайки нет ленты, поиска и
   рекомендаций → мама вставляет ссылку → «ИИ смотрит видео» → отчёт (возраст, тревожные
   моменты, полезный кусок и вопросы) → «Одобрить» → ёжик у Зайки; киоск (Android) и
   «Гид-доступ» (iPhone); прозвище вместо имени. Озвучка — 12 фраз диктора и 1 фраза совёнка,
   48 с.
3. **«Смотрит часами, а в голове пусто»** — обучение. Тёмная лента: мультик за мультиком, все
   досмотрены, счётчик «без перерыва» добегает до 3:00:00, экран гаснет — облачко «пусто».
   Дальше урок Зайки: карточки (лиса, медведь, слово вслух) → мультик о том же («3 минуты, а не
   3 часа») → вопрос совёнка «Кто спит зимой?» → «Правильно, медведь!»; у мамы «Прогресс»
   (89 % верно с первого раза, «Повторить» — что само встанет в уроки) и «План» с темой недели.
   Диктор — «Джордж», 10 фраз; совёнок — 3 (его «Медведь!» вырезан из «Правильно, медведь!»).
   44 с.
4. **«35 видов игр»** — нарезка игр Зайки. Ракета взлетает: «Это не мультик. Это игры, которые
   учат» → по навыкам, у каждой игры значок и название: счёт (Ракета, Рыбалка), память и
   внимание (Найди пару, Найди отличия), слух (Пианино), чтение (Слово из слогов), логика
   (Судоку, Который час?) → «Гонки»: совёнок объясняет задание голосом → «Лабиринт»: уровень
   растёт → стена плиток, счётчик до 35, «Без рекламы», «Без покупок» → пазл, наклейка, альбом
   → призыв. Диктор — «Джордж», 12 фраз (призыв — из №3); совёнок — 1. 38,5 с.
