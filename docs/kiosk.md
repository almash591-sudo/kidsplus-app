# Киоск для детских телефонов (Android, этап 6)

Киоск — приложение KidsPlus для Galaxy S20+, которое становится **владельцем устройства**:

- детское приложение открывается вместо рабочего стола и сразу после перезагрузки;
- нет кнопок «Домой» и «Недавние», шторки и уведомлений; работает только меню питания;
- нельзя сбросить телефон, ставить и удалять приложения, менять VPN и дату;
- **встроенный VPN** (sing-box, VLESS Reality / TLS) включён всегда; без VPN интернета нет;
- выйти можно только по **PIN телефона** — его задаёте при первой настройке.

## Что нужно на компьютере

Уже установлено (2026-10-10): JDK 21, Android SDK (platform-tools, build-tools 36, Android 16),
NDK 28, Go. Сборка:

```powershell
# sing-box libbox (один раз на версию, ~10 минут) — из Git Bash:
bash scripts/build-libbox.sh
# APK киоска (подписан ключом этого компьютера):
cd apps\kiosk; pnpm exec cap sync android; cd android; .\gradlew.bat assembleRelease
```

APK: `apps/kiosk/android/app/build/outputs/apk/release/app-release.apk`.

**Ключ подписи** — `%USERPROFILE%\.kidsplus\kiosk-release.jks`, пароль — в
`%USERPROFILE%\.gradle\gradle.properties`; копия с адресом подписки VPN — в OneDrive,
папка «KidsPlus — ключи». Не теряйте их: обновление
киоска ставится только с той же подписью. Если ключ потерян, телефон придётся вернуть в обычный
режим и провижинить заново.

## Настройка телефона (для каждого S20+)

1. **Сброс до заводских настроек**: Настройки → Общие настройки → Сброс → Сброс данных.
   Android разрешает назначить владельца устройства только телефону без аккаунтов.
2. При первом запуске подключите Wi-Fi и **пропустите** вход в Google и Samsung.
3. Включите отладку: Настройки → Сведения о телефоне → Сведения о ПО → 7 раз нажмите
   «Номер сборки»; затем Настройки → Параметры разработчика → **Отладка по USB**.
4. Подключите телефон по USB, подтвердите на телефоне «Разрешить отладку».
5. На компьютере:

   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\provision-device.ps1
   ```

   Скрипт сам передаёт в киоск подписку VPN из `%USERPROFILE%\.kidspluspn-subscription.txt`
   (команду принимает только adb с компьютера).

6. На телефоне откроются **Настройки телефона**:
   - придумайте PIN (4–6 цифр);
   - если VPN не подключён — вставьте ссылку `vless://…` или адрес подписки → «Подключить»;
   - когда появится «VPN: подключён ✅» — «Назад к ребёнку».
7. В детском приложении введите код привязки из кабинета («Устройства»).
8. Аккаунт Google при желании можно добавить потом.

## Меню родителя на телефоне

Удержите **правый верхний угол** экрана 3 секунды:

- в детском приложении — PIN кабинета → «Настройки телефона (VPN, Wi-Fi)» → PIN телефона;
- если связи нет (экран с луной) — сразу PIN телефона.

В настройках телефона: подписка VPN, Wi-Fi, «Выйти из детского режима на 30 минут»
(потом и после перезагрузки — снова киоск), смена PIN, «Вернуть телефон в обычный режим».

Подписка по адресу обновляется сама раз в сутки.

### В поездке (симкарты нет)

- **Wi-Fi** — обычная сеть с паролем или точка доступа с телефона родителя.
- **Wi-Fi со входом (отель, аэропорт, кафе)** — сети со страницей входа. Постоянный VPN такую
  страницу не пускает, поэтому кнопка снимает блокировку на 10 минут и открывает настройки Wi-Fi:
  выберите сеть, нажмите «Войти» и пройдите страницу. Вернитесь к ребёнку — блокировка включится
  снова, VPN подключится через новую сеть.
- **Bluetooth (наушники)** и **Все настройки телефона** (яркость, звук и прочее). Запреты детского
  режима — сброс, установка приложений, VPN — действуют и здесь. Кнопка «Домой» возвращает в киоск.

### Камера

Разрешения камеры и микрофона киоск выдаёт себе сам (владелец устройства) — системного вопроса
у ребёнка нет. Камера работает внутри детского приложения; системная камера недоступна.

### Звонки

Входящий звонок при погашенном экране: служба VPN киоска держит долгий запрос к серверу и при
звонке включает экран и открывает детское приложение. Звонки идут напрямую между телефонами
(WebRTC); если через VPN не соединяются — нужен TURN-ретранслятор: задайте переменную
`ICE_SERVERS` у api, например `{"iceServers":[{"urls":"turn:…","username":"…","credential":"…"}]}`.

### Радионяня

Включается в кабинете («Сейчас» → «🌙 Радионяня»). На телефоне — чёрный ночной экран: экран не
гаснет (иначе Android не даёт микрофон), но почти не светит. Телефон лучше держать на зарядке.

## Обновление киоска

Новый APK — тем же скриптом (`provision-device.ps1` сам видит, что киоск уже стоит, и обновляет).
В детском режиме Android не показывает запрос «Разрешить отладку по USB?»: при первом
подключении к компьютеру выйдите из детского режима на 30 минут и отметьте «Всегда разрешать
с этого компьютера».
Само детское приложение обновляется с сервера без переустановки.

## Вернуть телефон в обычный режим

Меню родителя → «Вернуть телефон в обычный режим», затем
`powershell -ExecutionPolicy Bypass -File scripts\unprovision-device.ps1` — удалит киоск.

## Если что-то не так

- **`dpm set-device-owner` пишет про аккаунты** — на телефоне есть аккаунт: сброс и шаг 2.
- **«VPN: ошибка»** — проверьте подписку в VPN-приложении на другом устройстве; «Подключить» ещё раз.
- **Экран с луной** — нет связи с сервером: Wi-Fi и VPN в настройках телефона.

## Обновление без кабеля (этап 15б)

Начиная с этой версии киоск обновляется сам: ночью, когда телефон на зарядке и экран выключен
(проверка — не чаще раза в 3 часа), он спрашивает сервер о новой версии, скачивает APK,
сверяет SHA-256 и ставит его тихо — владельцу устройства подтверждение не нужно. На время
установки запрет установки приложений снимается и возвращается сразу после.

Опубликовать новую версию:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\publish-kiosk.ps1
```

Скрипт собирает подписанный APK с номером версии «минуты с 2020 года» и загружает его на сервер
(`POST /api/kiosk/releases`, токен `KIOSK_PUBLISH_TOKEN` — создаётся при первом запуске,
хранится в `%USERPROFILE%\.kidsplus\kiosk-publish-token.txt` и в переменных api на Railway).

Первую версию с обновлением без кабеля нужно поставить по кабелю, как раньше.
Журнал обновлений на телефоне: `adb logcat -s KidsPlusUpdate`.

## Голосовое управление экраном малыша (этап 16в)

Для телефона на кронштейне (машина, дом): мама за рулём говорит «**Малыш, …**» — дальше,
громче, тише, песенки (мультики), логопед, шум (спать), мама (колыбельная), стоп (меню).
Распознавание офлайн (Vosk, маленькая русская модель внутри APK) — звук никуда не уходит;
слушается только этот словарь. Громкость меняет сам киоск (со шкалой на экране), остальное —
экран малыша. Микрофон включён, только пока открыт экран малыша.

Модель (~45 МБ в APK) в git не хранится — перед сборкой:

```powershell
powershell -ExecutionPolicy Bypass -File scriptsetch-vosk-model.ps1
```

Без модели киоск собирается и работает, только без голоса (в журнале `KidsPlusVoice` —
«модели распознавания нет»). Сборка — только для arm64 (Galaxy S20+).
