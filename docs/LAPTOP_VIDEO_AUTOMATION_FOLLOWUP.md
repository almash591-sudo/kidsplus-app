# Follow-up для ноутбучной сессии KidsPlus

Прочитай `docs/LAPTOP_VIDEO_AUTOMATION_REPORT.md` и продолжи исследование на ветке `docs/video-review-automation`.

## Что проверить и дополнить

1. В отчёте проверены YouTube IFrame/Data API и доступ локальной модели, но не разобран отдельный официальный путь Google Gemini API для публичных YouTube URL. Изучи актуальную документацию: https://ai.google.dev/gemini-api/docs/video-understanding . Она описывает YouTube URL input в API Interactions и помечает его как Preview без оплаты на момент публикации. Сравни этот путь с текущим `packages/providers/src/llm-gemini.ts`, который отправляет `fileData.fileUri` в `generateContent`. Объясни, может ли смена endpoint/API убрать `Gemini 402`, какие лимиты/условия/риски есть, и что нужно изменить в KidsPlus. Используй только официальные источники Google/YouTube. Не вызывай API и не отправляй ссылки на видео модели; это только документальное исследование, без списания средств и передачи медиаданных.
2. Оцени подходящие локальные video/audio-модели для RTX 3060 Laptop с 6 ГБ VRAM: реальные требования к памяти, квантование, качество временных меток/речи, лицензии и возможность запуска в текущем Windows/ComfyUI окружении. Не устанавливай модели и зависимости. Если никто из реалистичных кандидатов не помещается или качество недостаточно — укажи доказательства и точную причину. Это не снимает ограничение на доступ модели к YouTube-потоку.
3. Добавь десять региональных кандидатов из `docs/VIDEO_LIBRARY_1000_PLAN.md` в `docs/video-review-transfer.json`: пять про Россию и пять про Кыргызстан. Сохрани только имеющиеся метаданные, назначь каждому статус `blocked_content_not_accessed`; `summary`, `ageAssessment`, `safetyNotes`, `selectedSegment`, `quiz`, `evidence`, `confidence` оставь пустыми/null. Не выдумывай результаты просмотра и не меняй исходные 21 записи.
4. Обнови отчёт итогами, общим количеством строк передачи и отдельным явным статусом для региональных кандидатов. Добавь ссылки на официальные источники.

## Ограничения

- Не скачивай и не захватывай YouTube-видео/аудио; не используй `yt-dlp`, `youtube-dl`, неофициальные transcript API, обходы ограничений или запись экрана.
- Не запускай Gemini или другие платные/внешние inference API, не трать квоту, не читай/не выводи секреты.
- Не меняй production, Railway, очередь moderation worker, базу данных, назначения детям или API-ключи.
- Не устанавливай ничего на ноутбук, не меняй ComfyUI.
- Не коммить кандидатов как проверенные: передача остаётся метаданными со статусом блокировки.

## Результат

Обнови только документы на этой ветке, проверь JSON на валидность и отсутствие дубликатов ID, затем закоммить и отправь изменения в `origin/docs/video-review-automation`. В ответе перечисли коммит, выводы по каждому пункту и оставшиеся ограничения.
