# Ноутбучная проверка YouTube-кандидатов KidsPlus — follow-up, 2026-11-11

## Результат

В самой ноутбучной проверке локальный анализ видео не выполнен: медиа не скачивались/не захватывались, внешние inference API не вызывались, production и настройки ноутбука не менялись. Позже, отдельно и по явному разрешению владельца, одну ссылку отправили в Gemini Interactions API, используя ключ worker из Railway; запрос завершился `402` без результата. Ключ был прочитан только для вызова, не выводился и не сохранялся; настройки Railway, production, очередь, база данных, назначения детям и ComfyUI не менялись. Подробности — ниже и в `GEMINI_PREVIEW_PILOT_RESULT.md`.

Обнаружен официальный облачный технический путь, который не требует передачи локальной модели YouTube-потока: Gemini API Interactions принимает публичный YouTube URL как `video.uri`. Поэтому прежнее утверждение, что никакого официального URL-пути не найдено, следует считать уточнённым. Совместимость с текущим проектом проверили одной попыткой; она завершилась `402` до анализа. Доступ к Preview после исчерпания кредитов не подтверждён, а применимость условий к сторонним детским видео отдельно не оценена. Повторных вызовов и запуска в production не было.

## Ноутбук и локальные модели

- ОС: Windows 11 Home Single Language, 10.0.26200; GPU: NVIDIA RTX 3060 Laptop, 6144 MiB VRAM, свободно 5981 MiB на момент проверки; ОЗУ: около 15.4 GiB, свободно около 4.3 GiB.
- В ComfyUI присутствуют SDXL Base 1.0 и SD 1.5 для изображений. Мультимодальные видео/аудио-веса не установлены; ComfyUI/Python-процессов во время проверки не было. Настройки окружения не менялись.
- **SmolVLM2-2.2B-Instruct** — ближайший визуальный вариант: карточка модели указывает около 5.2 GB GPU RAM для видео-инференса и Apache 2.0. Это почти вся доступная VRAM ноутбука, без нормального запаса для ОС, кадров/контекста и соседних процессов. Ключевое ограничение: модельная карточка описывает image/video/text, не аудиовход; указанный язык NLP — English. Transformers умеет передавать видеометаданные для семплирования кадров/временных меток, но это не подтверждает точность выбранного обучающего фрагмента и вопросов по содержимому. Для русского аудио требуется отдельная ASR-модель и временное выравнивание.
- **Qwen2.5-Omni-3B** — подходящая по модальностям (текст, изображение, звук и видео) модель, но её официальный репозиторий сообщает минимумы для Transformers/BF16: 18.38 GB VRAM даже для 15-секундного видео, 22.43 GB для 30 секунд, 28.22 GB для 60 секунд; практический расход обычно не меньше 1.2×. На 6 GB она не помещается. Модель 3B помечена `qwen-research`, а не Apache 2.0; перед коммерческим использованием нужно отдельно оценить лицензию. Опубликованные Qwen GPTQ/AWQ 4-bit варианты относятся к 7B, а не решают заявленный минимум 3B.
- Раздельная схема SmolVLM2 + ASR технически возможна только при доступе к разрешённым локальным медиаданным и реализации последовательной/CPU выгрузки моделей; она добавляет зависимости и не была проверена. ASR-текст сам по себе не доказывает визуальные выводы, а семплирование кадров с редкой частотой может пропустить быстрые события. В текущем Windows/ComfyUI окружении готового рабочего конвейера нет; ничего не устанавливалось.

Источники моделей: [SmolVLM2-2.2B model card](https://huggingface.co/HuggingFaceTB/SmolVLM2-2.2B-Instruct), [Transformers: SmolVLM video processor](https://huggingface.co/docs/transformers/model_doc/smolvlm), [Qwen2.5-Omni repository and GPU memory table](https://github.com/QwenLM/Qwen2.5-Omni), [Qwen2.5-Omni-3B model card/license](https://huggingface.co/Qwen/Qwen2.5-Omni-3B).

## Официальный Gemini URL-путь и прежний `402`

Текущая реализация находится в `packages/providers/src/llm-gemini.ts`: `GeminiLlmProvider` формирует `Part[]`, кладёт `r.videoUrl` в `fileData.fileUri` и вызывает `models.generateContent` (`generateContent`). Этот код настроен на GenerateContent API, а не на документированный пример YouTube URL в Interactions API.

Актуальная [документация Gemini Video Understanding](https://ai.google.dev/gemini-api/docs/video-understanding) показывает запрос к `client.interactions.create(...)` / `POST /v1beta/interactions`, где публичная ссылка идёт как `input: [{type: "video", uri: "https://www.youtube.com/watch?v=..."}, ...]`. На странице метод отмечен **Preview**, сейчас — **available at no charge**, с прямой оговоркой, что pricing и rate limits могут поменяться. Документация предлагает модели `gemini-3.8-flash` в примерах и позволяет получать JSON через `response_format` schema; SDK для Interactions отличается от `models.generateContent`.

**Может ли это устранить `402`?** Документы описывают YouTube URL Preview как бесплатный на момент публикации, но проверить это можно только с конкретным проектом и ключом. По разрешению владельца один публичный кандидат (`Kfl5ihXpiUg`) был отправлен через `/v1beta/interactions` с `gemini-3.8-flash`. Endpoint вернул **HTTP 402 `RESOURCE_EXHAUSTED`** с сообщением, что предоплаченные кредиты проекта исчерпаны; результата анализа не было. Повторные запросы этим проектом/ключом не выполнялись. Следовательно, смена endpoint сама по себе проблему этого проекта не сняла, а доступность бесплатного Preview в текущем аккаунте не подтверждена. Код провайдера `generateContent` помечает любой `ApiError.status === 402` как billing/credit exhaustion; это эвристика, не классификация первопричины.

Для проверки в отдельной будущей задаче понадобится: (a) реализовать отдельный Interactions adapter, не подменять тихо существующий endpoint; (b) подать `video.uri` и текстовый prompt через Interactions schema; (c) перенести JSON Schema в `response_format: {type:"text", mime_type:"application/json", schema: ...}`; (d) проверить парсинг ответа, статус/лимиты и нормализацию ошибок; (e) только после явного разрешения владельца выполнить один тест на одном URL, без массовой очереди. Production-код здесь не менялся.

**Условия и риски:** Preview нестабилен; квоты/лимиты и тарификация могут измениться; принятие произвольных публичных ссылок не гарантирует доступность каждого видео, географии, embed-разрешений или постоянную обработку. Бесплатный уровень Gemini API указывает, что переданный контент может использоваться для улучшения продуктов Google; платный уровень указывает, что контент не используется таким образом. Один публичный URL был отправлен после явного разрешения владельца; запрос отклонён до анализа из-за исчерпанных предоплаченных кредитов. Перед дальнейшими запросами для детских материалов нужно отдельно принять решение по обработке данных, аккаунту и возможному пополнению/смене плана.

YouTube Terms разрешают просмотр/прослушивание для личного некоммерческого использования и воспроизведение через встроенный плеер; прочее использование контента требует, чтобы оно было специально разрешено сервисом, имелось письменное разрешение YouTube/правообладателя или действовало применимое право. Gemini — официальный API Google, но найденная документация Google не является отдельным юридическим разрешением правообладателей на анализ каждого ролика в продукте KidsPlus. Совместимость конкретного коммерческого/образовательного случая следует проверить с правообладателем/YouTube policy/compliance до production. Это не требует локального извлечения потока, но передаёт URL и запрос облачному провайдеру.

Источники: [Gemini Video Understanding / YouTube URL Preview](https://ai.google.dev/gemini-api/docs/video-understanding), [Interactions API](https://ai.google.dev/api/interactions-api), [structured JSON output](https://ai.google.dev/gemini-api/docs/structured-output), [Gemini API pricing/data handling](https://ai.google.dev/gemini-api/docs/pricing), [Gemini API terms](https://ai.google.dev/gemini-api/docs/terms), [YouTube Terms of Service](https://www.youtube.com/t/terms).

## Итог и следующий шаг

- **Локальный video+audio анализ на этом ноутбуке:** нет подходящей целостной модели в пределах 6 GB с приемлемым запасом; Qwen Omni превышает память, SmolVLM2 не слышит звук.
- **Официальный Google URL-путь:** документирован для публичного YouTube URL через Gemini Interactions API, Preview/free на момент публикации, но текущий проект ответил `402` из-за исчерпанных предоплаченных кредитов. Этот endpoint не обошёл блокировку проекта.
- **Содержательная проверка всех 31 кандидата:** остаётся заблокированной. Следующий рабочий шаг — владелец восстанавливает доступ/кредиты Gemini или выбирает другой допустимый провайдер/лицензированный источник; затем сначала повторяется только один пилот и проверяется результат. До успешного анализа ничего не добавлять в production и не назначать детям.
