## Что позволяют документированные интерфейсы YouTube

1. [YouTube IFrame Player API](https://developers.google.com/youtube/iframe_api_reference) позволяет встроить официальный плеер, управлять воспроизведением и получать состояние/события плеера. В документированном API нет метода для чтения кадров, аудиосэмплов или передачи медиапотока локальной модели. Error 153 в документации описан как отсутствие HTTP Referer или эквивалентной идентификации API-клиента; запуск embed из `file://` не является подходящей интеграцией.
2. [YouTube API Services Developer Policies](https://developers.google.com/youtube/terms/developer-policies) запрещают без предварительного письменного разрешения скачивать, импортировать, резервировать, кэшировать или хранить копии аудиовизуального контента. Живой встроенный playback предназначен для просмотра в плеере. Извлечение его медиапотока или его захват для подачи в локальную модель выходит за документированный интерфейс и условия этой задачи.
3. [YouTube Data API captions.list](https://developers.google.com/youtube/v3/docs/captions/list) требует авторизацию; [captions.download](https://developers.google.com/youtube/v3/docs/captions/download) требует права редактировать видео и возвращает файл дорожки субтитров. Это не путь к субтитрам чужих кандидатов и не доступ к живому аудио/видео. Неофициальные caption/transcript API не использовались.
4. Data API метаданные, публичность, embed-разрешение и `madeForKids` не подтверждают фактическое содержание ролика и не дают модели доступ к нему.

**Точный блокер:** для автоматического содержательного анализа локальной модели нужны декодированные кадры и звук. У официального YouTube embed/API нет документированной функции предоставления этих данных сторонней модели; добывание их из playback потребовало бы извлечения/записи потока или обхода ограничений, что прямо исключено заданием. Поэтому соответствие критериям автоматизации доказать на этих YouTube-кандидатах нельзя.

## Минимальные допустимые варианты продолжения

Выберите один источник содержимого, доступный анализатору на законном основании:

- предоставить лицензированные локальные видеофайлы/аудиодорожки с разрешением на анализ; тогда можно оценить размеры и лицензию подходящей локальной модели для 6 ГБ VRAM до установки;
- разрешить конкретный облачный video-analysis сервис и подтвердить допустимость передачи ему этих роликов, бюджет и условия обработки;
- восстановить существующий прямой YouTube URL-анализатор KidsPlus у провайдера, который поддерживает передачу URL напрямую. Текущий worker уже делает такую передачу, но отвечает `Gemini 402`; повторно Gemini не запускался. Для такого пути владелец должен отдельно подтвердить допустимость нового провайдера и его условий обработки.

Наиболее малое изменение ограничений для доказуемого локального POC — предоставить один лицензированный локальный файл с разрешённым анализом. Если требуется именно сторонний YouTube-контент без скачивания и без облачного URL-анализатора, одного исправления embed/Referer недостаточно: нужно официальное разрешение/интерфейс, который прямо допускает доступ модели к аудио и кадрам.
